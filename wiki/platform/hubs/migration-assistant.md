Migration Assistant (`SwagMigrationAssistant`) is the Shopware extension that connects an existing shop system (typically Shopware 5, or another Shopware 6 instance) to a target Shopware 6 shop so products, customers and other data can be migrated once and later re-migrated or updated. Come here instead of grepping when you need to explain how the extension is used from the Administration, or when you need the plugin's extension points (profiles, gateways, readers, converters, writers, premapping, error resolution, logging, media processing) to extend it — the extension's own code is not part of `vendor/shopware/core|storefront|administration`, so these pages are the only source of its class and table names available here.

The 6.7 docs split the single 6.6 concept page into one page per building block:
