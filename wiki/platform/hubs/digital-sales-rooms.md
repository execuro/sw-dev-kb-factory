Digital Sales Rooms (DSR) is a licensed Shopware extension (not open source) that runs interactive live-video shopping events, combining a store-integrated presentation layer, Daily.co video calls, and a Mercure realtime service. It ships as two parts: an admin-side plugin (`SwagDigitalSalesRooms`) and a standalone Nuxt 3 frontend app (`dsr-frontends`), hosted on its own domain, separate from the Storefront. Come here instead of grepping directly when you need the full install → third-party setup → configuration → deploy → customize sequence, or when you need to know which of the near-duplicate 6.6/6.7 pages applies to your target version. The 6.6 and 6.7 doc trees are near-identical in structure and content; page-by-page differences are mostly wording and added detail (e.g. 6.7 adds a CLI configuration path and a dedicated Mercure setup guide). The `platform/func/...` page is the separate merchant-facing guide to the "Sales Agent" presentation UI itself.
