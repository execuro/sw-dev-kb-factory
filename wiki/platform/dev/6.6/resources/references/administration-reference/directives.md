## What it is
This is an overview of the directives registered globally to Vue in the Shopware 6 Administration. They behave the same as normal Vue directives, differing only in how they are registered.

## Key steps / config
| Directive | Task |
|---|---|
| `autofocus` | Focuses an `<input>` in an element on insertion. |
| `dragdrop` | Enables the drag and drop functionality of the CMS. |
| `popover` | Automatic edge detection of the element's placement. |
| `responsive` | Adds methods to add responsive element classes. |
| `tooltip` | Provides utility functions to display tooltips. |

## Essential identifiers
- `autofocus`
- `dragdrop`
- `popover`
