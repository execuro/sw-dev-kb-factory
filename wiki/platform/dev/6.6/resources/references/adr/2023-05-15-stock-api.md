## What it is
Architecture decision record introducing a new, extensible stock manipulation API (`AbstractStockStorage`) that replaces the old dual `stock`/`available_stock` model with one realtime `stock` field.

## When to use
Relevant when customizing stock handling (e.g. ERP integration, multi-warehouse), debugging stock discrepancies, or migrating code that reads/writes `availableStock`.

## Key steps / config
- Feature flag `STOCK_HANDLING` opts in early; removed in 6.6 where the new behavior becomes default.
- New abstract class:
```php
abstract class AbstractStockStorage
{
    abstract public function getDecorated(): self;
    abstract public function load(StockLoadRequest $stockRequest, SalesChannelContext $context): StockDataCollection;
    abstract public function alter(array $changes, Context $context): void;
    abstract public function index(array $productIds, Context $context): void;
}
```
- Supporting DTOs: `StockDataCollection`, `StockData` (with `productId`, `stock`, `available`, `minPurchase`, `maxPurchase`, `isCloseout`), and `StockAlteration` (`lineItemId`, `productId`, `quantityBefore`, `newQuantity`).
- New `BeforeWriteEvent` on `EntityWriteGateway` provides `addSuccess`/`addError` callbacks.
- `ProductIndexer` depends on `AbstractStockStorage` and `StockUpdater`; when `STOCK_HANDLING` is enabled it calls `AbstractStockStorage::index`, otherwise `StockUpdater::update`.
- New `OrderStockSubscriber` calls `AbstractStockStorage::alter` for order placed/cancelled/reopened and line-item add/remove/update/product-change scenarios.
- Config key `shopware.stock.enable_stock_management` (set to `false`) disables internal stock handling.
- New method `AvailableCombinationLoader::loadCombinations(string $productId, SalesChannelContext $salesChannelContext): AvailableCombinationResult` replaces `load()`.

## Gotchas
`StockUpdater` and its filters (`AbstractStockUpdateFilter`, `StockUpdateFilterProvider`, `ExcludeMultiWarehouseStockUpdateFilter`) are deprecated and removed in 6.6; decorators replace filter-based extension. `availableStock` is kept but write-protected and deprecated, mirroring `stock`, since integrations rely on it. `AvailableCombinationLoader::load` is deprecated for 6.6 in favor of `loadCombinations`.

## Version notes
In Shopware 6.6 (or with `STOCK_HANDLING` enabled), `availableStock` becomes write-protected and mirrors `stock`; `StockUpdater` and its filters are removed.
