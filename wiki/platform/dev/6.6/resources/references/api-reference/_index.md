## What it is
The API Reference section indexes the two Shopware API documentation sets: the Store API reference and the Admin API reference. Each provides detailed information about the available endpoints, methods, parameters, request and response formats, and authentication mechanisms of that API.

## When to use
Consult this page when you need to pick the right API for a task: use the Store API for customer-facing storefront functionality — products, customer interactions, shopping carts, and other data that affects the frontend user experience — available to both anonymous and authenticated users. Use the Admin API for backend and administrative functions such as structured data exchanges, bulk operations, data synchronization, and import/export tasks.

## Key steps / config
The page links out to two externally hosted reference documents:
- Store API reference: `https://shopware.stoplight.io/docs/store-api/38777d33d92dc-quick-start-guide`
- Admin API reference: `https://shopware.stoplight.io/docs/admin-api/twpxvnspkg3yu-quick-start-guide`

These references guide correct request syntax, expected input/output formats, the necessary authentication mechanisms, and how to effectively use the functionality each API provides.

## Essential identifiers
- `Store API reference` — customer-facing endpoints (products, cart, customer interactions), for anonymous and authenticated users
- `Admin API reference` — backend/administrative endpoints (bulk operations, data synchronization, import/export)
