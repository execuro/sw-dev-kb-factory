## What it is

The landing page for Shopware's contributor and reader guidelines, split into three areas: coding standards, end-to-end testing best practices, and documentation style/process.

## When to use

Start here when you need to find the specific guideline set (code, testing, or documentation) that applies to a change you are making or reviewing.

## Key steps / config

The guidelines are organized into three sections:
- Code section — coding standards that keep the codebase consistent and understandable.
- Testing section — best practices for writing end-to-end tests.
- Documentation section — language style, grammar, markdown syntax, and the documentation process.
