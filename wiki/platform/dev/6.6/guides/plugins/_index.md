## What it is

This is the index page for the "Extensions" section. It explains that a Shopware developer's main work is building extensions that enhance or modify Shopware's functionality, and that Shopware offers different types of extensions, each with its own benefits and implications.

## When to use

Use this page when deciding which extension approach to use for a customization task, or as an entry point into the introduction guides for each extension type.

## Key steps / config

To compare the available approaches before choosing one, the source points to an extension overview article. To dive straight into building, it links to three introduction guides: the plugin base guide, the app base guide, and the theme base guide. Together these guides provide the essential information on how to create, configure, and extend a store with Shopware extensions.

## Essential identifiers

- Plugins — one extension type, with its own base guide
- Apps — another extension type, with its own base guide
- Themes — another extension type, with its own base guide
- Extension overview article comparing all approaches
