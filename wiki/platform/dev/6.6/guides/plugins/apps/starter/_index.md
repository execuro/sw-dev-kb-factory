## What it is

This is the index page for the app starter guides, a set of guides that walk through extending the platform's functionality using the app system rather than a plugin.

## When to use

Consult this section when starting to build an app and needing to know what the following starter guides cover: exposing custom API endpoints with App Scripts, exchanging data with Shopware from the app, or adding custom extensions to the Administration.

## Key steps / config

The starter guides section covers three areas:

- Creating custom API endpoints using App Scripts.
- Reading and writing data to and from Shopware from within an app.
- Creating custom admin extensions.

## Essential identifiers

- `App Scripts` — the mechanism used to build custom API endpoints for an app.
