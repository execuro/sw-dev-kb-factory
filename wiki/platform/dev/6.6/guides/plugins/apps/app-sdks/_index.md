## What it is

The Shopware app SDK is a family of libraries (PHP and JavaScript) that let you build applications and plugins extending the functionality of the Shopware e-commerce platform. It provides the resources and tools needed to simplify development and integrate custom logic into the Shopware environment.

## When to use

Use an App SDK instead of implementing app registration, signing, and context-handling logic yourself when building an app that communicates with an external backend.
