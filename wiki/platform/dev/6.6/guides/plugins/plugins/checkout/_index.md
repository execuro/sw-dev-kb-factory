## What it is

This section is the landing page for guides about checkout plugins in Shopware. A checkout plugin improves the checkout process for customers, adding features such as guest checkout, custom fields, multiple payment options, address validation, order summaries, shopping cart handling, shipping method selection, and promotional code support.

## When to use

Consult this section when building a plugin that touches any part of the customer-facing checkout flow — payment, shipping, address entry, order review, or promotional codes — rather than storefront or administration areas unrelated to checkout.

## Key steps / config

The section frames the purpose of checkout plugins as ensuring a smooth and efficient checkout experience for customers, while giving businesses the flexibility to meet their own specific requirements through the listed feature areas: guest checkout, custom fields, multiple payment options, address validation, order summaries, shopping cart, shipping method selection, and promotional code support.
