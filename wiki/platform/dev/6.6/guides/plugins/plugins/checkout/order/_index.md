## What it is
Index page for the checkout Order guide section. It lists the essential order-related capabilities available to plugins in Shopware: order placement, order management, order status tracking, order customization, order notifications, and order history.

## When to use
Use this section when a plugin needs to extend or customize how orders are placed, managed, tracked, or communicated to customers — these functions are provided by the Shopware core but plugins offer the flexibility to extend or customize them based on specific business needs.
