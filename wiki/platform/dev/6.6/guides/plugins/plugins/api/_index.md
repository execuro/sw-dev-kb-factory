## What it is

This section is the landing page for guides about commercial plugin APIs in Shopware. Commercial plugins are pre-built extensions developed by third-party vendors that provide specific features and integrations; in some cases these plugins expose their own APIs so developers can interact with the plugin's functionality programmatically.

## When to use

Consult this section when a commercial plugin's own API needs to be consumed or extended — for example to customize plugin behavior or connect it with an external system — rather than when working with Shopware's core platform APIs directly.

## Key steps / config

The section frames commercial plugins and their APIs as complementary: plugins offer ready-to-use solutions for specific features, while their exposed APIs give developers the flexibility to build custom integrations and extend that functionality further, expanding what the Shopware platform can do overall.
