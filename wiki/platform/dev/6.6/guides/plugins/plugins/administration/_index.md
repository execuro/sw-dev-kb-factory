## What it is

This is the section index for extending the Shopware Administration panel through plugins: adding features and customization options for managing the e-commerce platform.

## When to use

Use the guides in this section when a plugin needs to tailor the Administration interface to a business's specific needs — for example adding custom sections, modules, services or functionalities to streamline a workflow or improve the user experience, rather than only changing Storefront-facing behavior.

## Key steps / config

A plugin can extend the Administration in several ways, all covered by the guides in this section:

- Adding custom sections and modules to the Administration interface.
- Adding custom services or functionalities used by the Administration.
- Configuring dashboards shown to the user.
- Adjusting menu structures so custom features are reachable.
- Configuring permissions that control access to custom features.
- Configuring settings screens for a plugin's own configuration.

Together these let a plugin build a customized and efficient administration experience aligned with a business's specific requirements.

## Essential identifiers

- Administration panel — the Shopware admin interface this section's guides extend.
- Dashboards, menu structures, permissions, settings — the configurable areas covered by this section.
