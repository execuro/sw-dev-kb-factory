## What it is
Index page for the plugin Content guide section. It covers content-related capabilities in Shopware: content management, email management, SEO optimization, sitemap generation, and media management.

## When to use
Use this section when a plugin needs to extend or customize how content, mail templates, SEO, sitemaps, or media are handled. These functions enhance website content, facilitate effective communication, improve search engine visibility, and streamline media organization within the e-commerce platform.
