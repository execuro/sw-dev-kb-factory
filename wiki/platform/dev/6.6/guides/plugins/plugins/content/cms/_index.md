## What it is
Index page for the plugin CMS guide section. Shopware CMS creates and manages content using blocks and elements, and the CMS plugin area lets you add and organize these blocks from a plugin.

## When to use
Use this section when a plugin needs to add custom CMS blocks or elements, feed content elements with data (e.g. product information, categories, or data from APIs), or manage CMS functionality via the Shopware Admin SDK.

## Key steps / config
- Blocks are reusable sections of content that can be placed on multiple pages; their appearance and layout can be customized.
- To build engaging, visually appealing pages inside a block, add and configure content elements such as text, images, videos, and sliders.
- Content elements can be populated with data such as product information, categories, or dynamic content from APIs.
- The CMS core functions can also be accessed and managed through the Shopware Admin SDK, which provides developers with tools and APIs to interact with the CMS functionality for more advanced customization.
- Overall, the plugin facilitates creating, customizing, and managing engaging content through blocks, elements, and the flexibility the Admin SDK provides, so businesses can build pages with dynamic and relevant content.

## Essential identifiers
- Shopware Admin SDK (used to interact with CMS functionality programmatically)
- CMS blocks and CMS elements (the two core building units of a CMS page)
