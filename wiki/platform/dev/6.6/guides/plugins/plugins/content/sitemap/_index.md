## What it is
Index page for the plugin Sitemap guide section. Shopware Sitemap offers the ability to add sitemaps and modify sitemap entries within the e-commerce platform.

## When to use
Use this section when a plugin needs to provide search engines with a structured overview of the site's content, or needs to customize what is included in generated sitemaps.

## Key steps / config
- Create custom sitemaps tailored to specific requirements, including relevant pages, categories, products, or other content sections as needed.
- Modify existing sitemap entries — for example, change entry URLs or override SEO URLs used in the sitemap.
- Both capabilities exist to ensure the website's content is efficiently crawled and indexed by search engines, which helps improve visibility, search engine rankings, and traffic.
- These capabilities are provided by the Shopware core sitemap generation feature but can be extended or customized through a plugin.
