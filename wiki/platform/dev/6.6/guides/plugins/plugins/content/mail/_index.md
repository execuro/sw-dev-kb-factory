## What it is
Index page for the plugin Mail guide section. Shopware Mail offers the ability to add mail data and configure mail templates for various email communications within the e-commerce platform.

## When to use
Use this section when a plugin needs to add data to transactional emails, order notifications, customer communication, marketing campaigns, or newsletters — for example tailoring emails to specific events or triggers so communication stays timely and personalized.

## Key steps / config
- Mail templates can receive additional mail data supplied by a plugin, which then becomes usable inside the template.
- The mail template tooling lets users design and format email content — text, images, logos, and dynamic variables — to personalize messages and keep branding consistent across all outgoing emails.
- Typical use cases: transactional emails, order updates, customer communication, marketing campaigns, and newsletters.
- By using this capability, businesses can effectively engage customers and keep them informed about order updates, promotions, or other relevant information.
