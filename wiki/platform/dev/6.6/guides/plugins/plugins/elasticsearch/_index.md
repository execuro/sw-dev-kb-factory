## What it is
Index page for the plugin Elasticsearch guide section. It covers extending fields of an entity to the Elasticsearch engine to expand Shopware's search capabilities.

## When to use
Use this section when a plugin needs users to be able to search on additional entity attributes or metadata that are not indexed by default.

## Key steps / config
Extending entity fields to the Elasticsearch engine enables more targeted and precise search results, allowing users to search based on additional attributes or metadata and enhancing the overall search experience for customers.
