## What it is

This is the landing page for the "Rule" section of the plugin guides. The Rule Builder allows
users to add custom rules to create dynamic conditions and actions within the e-commerce
platform.

## When to use

Use the Rule Builder when a plugin needs to define criteria based on attributes such as
customer data, cart contents, order details, or other relevant factors, and trigger specific
actions once those criteria match.

## Key steps / config

The source describes the Rule Builder conceptually rather than a step-by-step procedure on
this landing page:

- Define specific criteria based on customer data, cart contents, order details, or other
  relevant factors.
- Trigger specific actions from those criteria, such as applying discounts, displaying
  personalized content, or adjusting pricing based on specific conditions.

The Rule Builder is described as empowering highly tailored and automated experiences for
customers, extending the flexibility and customization options within the Shopware framework.
