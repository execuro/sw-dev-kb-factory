## What it is

This is the landing page for the "Flow" section of the plugin guides. The flow builder plugin
allows businesses to create and manage custom workflows and automation within the e-commerce
platform, enhancing efficiency and streamlining processes. It mainly comprises actions and
triggers.

## When to use

Use this section when a plugin needs to add a custom action a flow can execute, or a custom
trigger that can start a flow — for example to respond dynamically to specific events or
changes in the e-commerce platform.

## Key steps / config

The source describes two building blocks a plugin can add:

- Custom flow actions — automate a task or process; these are the things a flow *does*.
- Custom flow triggers — the events or conditions that *initiate* the execution of a flow.

Both can be defined and executed within the flow builder, letting businesses respond
dynamically to specific events or changes in their e-commerce platform.

## Essential identifiers

- Flow builder — the platform feature this section documents.
- Flow action, flow trigger — the two customization points named in the source.
