## What it is

This is the landing page for the "Store API" section of the plugin guides. The Store API
plugin support in Shopware enables adding custom endpoints to the existing Store API, and
overriding or extending the functionality of existing endpoints.

## When to use

Use this when a plugin needs to expose new API functionality through the Store API, or needs
to customize the behavior of an existing Store API endpoint rather than accepting the default
behavior.

## Key steps / config

The source describes two capabilities available from a plugin on this landing page:

- Adding custom endpoints to the existing Store API.
- Overriding or extending the functionality of existing Store API endpoints.

This lets developers customize the API according to specific requirements, providing
additional functionality or modifying the behavior of existing endpoints.

## Essential identifiers

- Store API — the API this section documents extending and customizing.
