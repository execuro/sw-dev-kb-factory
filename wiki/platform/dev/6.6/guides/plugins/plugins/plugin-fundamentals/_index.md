## What it is

This is the landing page for the "Plugin fundamentals" section of the plugin guides. Shopware
plugins are PHP-based extensions that enhance the functionality of the Shopware e-commerce
platform.

## When to use

Use this section as the starting point for understanding how a Shopware plugin is structured
and how it behaves through its lifecycle, before diving into more specific framework guides.

## Key steps / config

The source outlines the core building blocks a plugin author needs to know:

- A specific directory structure that plugins follow.
- A lifecycle covering installation, activation, deactivation, and uninstallation.
- Hooks and events used to interact with core functionality.
- Controllers, services, and models to handle specific tasks.
- Plugin configuration options that can be defined.
- Integration with various parts of Shopware.

## Essential identifiers

- Plugin lifecycle stages named in the source: installation, activation, deactivation,
  uninstallation.
- Plugin building blocks named in the source: controllers, services, models, configuration
  options.
