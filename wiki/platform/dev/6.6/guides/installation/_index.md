## What it is

This is the index page for the "Installation" section. It introduces the ways to set up Shopware on a local machine as a foundation for development, together with the most useful services for data storage and the web server.

## When to use

Use this page as a starting point when deciding how to get a local Shopware instance running for development, before choosing a specific setup method from the linked "Setups" section.

## Key steps / config

Regardless of the chosen setup method, all of them are based on the [Project template](platform/dev/6.6/guides/installation/template.md): a Composer project that requires Shopware itself, which can then be further customized with additional extensions, themes, or configurations. The available setups for Shopware 6 are listed on the "Setups" sub-page.

## Essential identifiers

- Project template (Composer project requiring Shopware)
- Setups sub-section listing the available local setup methods
