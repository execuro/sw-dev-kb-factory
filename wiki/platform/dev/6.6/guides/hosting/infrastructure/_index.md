## What it is

This is the index page for the hosting infrastructure section. It lists the infrastructure components a Shopware hosting setup is built from: Elasticsearch for advanced search, a database cluster for data storage, a filesystem for media files, a message queue for asynchronous communication, a rate limiter for request management, and a reverse HTTPS proxy for secure communication.

## When to use

Use this page as a starting point when planning or reviewing the infrastructure a Shopware installation depends on, before drilling into the more detailed sub-sections for each component (such as Elasticsearch).
