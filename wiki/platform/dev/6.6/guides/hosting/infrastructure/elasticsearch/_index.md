## What it is

This is the index page for the Elasticsearch section of the hosting infrastructure guides. Elasticsearch is described as a robust search engine that can be integrated into Shopware to provide advanced search capabilities, including support for AND/OR operations.

## When to use

Use this page as the entry point when you need to set up, configure, debug, resolve indexing issues with, or optimize the performance of Elasticsearch as the search backend for a Shopware store; the linked sub-sections cover these tasks in more detail.
