## What it is
Framework configurations for Shopware originate in the Symfony FrameworkBundle and are partially documented in this guide.

## When to use
Consult this page when you need to configure framework-level settings for a Shopware installation and want to know where those settings come from upstream.

## Key steps / config
The canonical reference for these settings is the Symfony FrameworkBundle configuration reference, cited in the source as `https://symfony.com/doc/current/reference/configuration/framework.html`; this guide documents only part of it.

## Essential identifiers
- Symfony FrameworkBundle
