## What it is

This is the index page for the Deployments guide section, introducing the fundamental steps to deploy Shopware 6 to a specific infrastructure and how to build assets for the Administration and Storefront without a database.

## When to use

Use this as the entry point when planning a Shopware 6 deployment strategy, particularly when the build process needs to run without direct access to the production database.
