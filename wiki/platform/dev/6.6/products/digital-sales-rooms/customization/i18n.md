## What it is
How to customize the internationalization (i18n) setup of the DSR frontend using the Nuxt layer concept, so the default i18n functionality is extended or overridden rather than modified in place.

## When to use
Use this when translations or language settings for a DSR deployment need to differ from the defaults without editing core files.

## Key steps / config
1. Configure i18n settings in `nuxt.config.ts`, which defines the language directory and any language-specific overrides:

```js
modules: [
  "@nuxtjs/i18n",
],
i18n: {
  langDir: "./i18n/src/langs/",
  ...i18nConfig,
},
```

2. In your custom layer, create an i18n folder structure mirroring the default layer's, but only including the files you need to override.
3. Look at the `example` layer to see the expected structure.

## Essential identifiers
- `nuxt.config.ts`
- `@nuxtjs/i18n`
- `langDir`
