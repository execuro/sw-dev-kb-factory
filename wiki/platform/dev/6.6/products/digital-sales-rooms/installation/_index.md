## What it is

This is the section index for installing the Digital Sales Rooms (DSR) plugin into an existing Shopware platform installation; it does not cover installing Shopware itself. Installation is split into two parts described in the following pages: installing the plugin on the admin side, and installing and running the separate frontend template.

## When to use

Use this page as the entry point once you already have a running Shopware platform and want to add DSR to it — for example an example setup where Shopware runs at `https://shopware.store` and the DSR frontend app runs at `https://dsr.shopware.io`.

## Essential identifiers

- `SwagDigitalSalesRooms` — the DSR plugin's technical name, used later in the admin-side installation commands.
