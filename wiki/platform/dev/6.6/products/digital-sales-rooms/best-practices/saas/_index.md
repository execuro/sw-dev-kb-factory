## What it is
Notes for Beyond merchants using Shopware SaaS: the Digital Sales Rooms plugin is already installed in the SaaS instance, visible as a Digital Sales Rooms section under the Marketing menu item.

## When to use
Use this when running Shopware as a Beyond SaaS merchant and setting up DSR, since the plugin itself does not need installing but several other steps still do.

## Key steps / config
Even though the plugin is pre-installed on SaaS, these steps still need to be completed for DSR to function fully:
- [Deploy the frontend app](platform/dev/6.6/products/digital-sales-rooms/best-practices/app-deployment/_index.md)
- [Set up 3rd parties](platform/dev/6.6/products/digital-sales-rooms/setup-3rd-party/_index.md)
- [Configuration](platform/dev/6.6/products/digital-sales-rooms/configuration/_index.md)
