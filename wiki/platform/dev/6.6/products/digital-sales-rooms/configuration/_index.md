## What it is

This is the section index for configuring the Digital Sales Rooms (DSR) plugin, a Shopware Beyond extension (installed under the technical name `SwagDigitalSalesRooms`) that adds a video-call based B2B sales room feature to a shop. The index page itself does not describe individual settings; it introduces the configuration chapter and points readers to the following, more detailed configuration pages that walk through each setting in turn.

## When to use

Consult this page as the entry point once the DSR plugin has already been installed (both the admin-side plugin and the frontend template) and you now need to configure it — for example setting up connection details for video/audio providers, sales-channel domains, or other DSR plugin options described on the child configuration pages that follow this index.

## Essential identifiers

- `SwagDigitalSalesRooms` — the DSR plugin's technical name, referenced throughout the configuration and installation chapters.
