## What it is

Introduction contrasting two Shopware cloud hosting offerings: Shopware PaaS, a generic platform-as-a-service supporting various applications and multiple cloud providers, and Shopware PaaS Native, a Shopware-specific offering tightly integrated and controlled on AWS.

## When to use

Choose Shopware PaaS if you need flexibility to define your own infrastructure as code across cloud providers, accepting more infrastructure/setup responsibility. Choose Shopware PaaS Native if you want Shopware to manage the underlying configuration on AWS so you can focus on application development, at the cost of specialization to a single controlled environment.

## Essential identifiers

- Shopware PaaS (generic, multi-cloud, infrastructure-as-code)
- Shopware PaaS Native (Shopware-managed, AWS-only)
