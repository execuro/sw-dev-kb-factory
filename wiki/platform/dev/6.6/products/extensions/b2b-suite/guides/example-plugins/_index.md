## What it is
An index of downloadable example plugins that each showcase one B2B Suite extension topic covered elsewhere in these guides.

## Key steps / config
The example plugins and what each demonstrates:

- `B2bAcl` — the ACL implementation, including frontend usage, CRUD and listing usage.
- `B2bAjaxPanel` — how to use the Ajax Panels.
- `B2bAuditLog` — an implementation of the audit log component.
- `B2bAuth` — logging in as a certain user.
- `B2bLogin` — exchanging the e-mail login with a staff-number login.
- `B2bRestApi` — the `RestApi` routing.
- `B2bServiceExtension` — how to extend a service.
- `B2bTemplateExtension` — how to extend the `SwagB2bPlatform` templates.
