## What it is

Notes that B2B Suite Administration modules are built following the official Shopware Administration plugin documentation, and points to a separate user-facing guide for day-to-day usage of the B2B Suite administration screens.

## When to use

Use this as the starting point when working on or extending the B2B Suite's administration-side modules, since it clarifies which conventions those modules follow.

## Key steps / config

The source gives two references rather than inline steps: the official Shopware plugin Administration documentation, which the B2B Suite Administration modules are built to follow, and a separate "User documentation" guide (titled "b2b-suite-administration" in Shopware's docs) that covers the administration modules from an end-user perspective in more depth.
