## What it is

The Migration Assistant is the Shopware extension that establishes a connection between an existing shop system (for example Shopware 5) and Shopware 6, so that data such as products and customers can be migrated or kept in sync.

## When to use

Use it when moving a shop's data (products, customers, etc.) from a source shop system into Shopware 6, or when updating already-migrated data after the initial migration.

## Key steps / config

Establishing a connection between the source system and Shopware 6 lets you run a first complete migration, after which individual datasets can be migrated or updated again as needed.
