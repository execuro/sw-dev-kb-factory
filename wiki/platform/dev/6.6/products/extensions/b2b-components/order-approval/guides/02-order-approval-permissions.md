## What it is

This page lists all permissions available in the Order Approval component, for use when assigning roles to employees.

## Key steps / config

Approval rule permissions:

| Permission | Description |
|---|---|
| `Can create approval rules` | Allows creating approval rules |
| `Can update approval rules` | Allows updating approval rules |
| `Can delete approval rules` | Allows deleting approval rules |
| `Can read approval rules` | Allows viewing approval rules |

Pending order permissions:

| Permission | Description |
|---|---|
| `Can approve/decline all pending orders` | Approve/decline all pending orders |
| `Can approve/decline pending orders` | Approve/decline assigned pending orders |
| `Can view all pending orders` | View all pending orders |

## Essential identifiers

- `Can create approval rules`, `Can update approval rules`, `Can delete approval rules`, `Can read approval rules`
- `Can approve/decline all pending orders`, `Can approve/decline pending orders`, `Can view all pending orders`
