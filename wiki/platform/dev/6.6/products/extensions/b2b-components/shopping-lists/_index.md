## What it is

Describes the *Shopping lists* component of the B2B components, which is designed to help users manage recurring or planned shopping needs by grouping products into reusable lists rather than only using the cart.

## When to use

Relevant when a B2B storefront needs to let customers create, edit and organize multiple named lists of products — for example for a weekly grocery trip or a special event — separately from an active cart.

## Key steps / config

The component provides, per the source:

- Creating, editing, and organizing shopping lists.
- Item categorization within a list.
- Quantity tracking per item.
- Marking items as purchased.

## Gotchas

The source frames the component purely at the feature level (what it lets a user do), without documenting specific APIs, classes or config keys on this overview page — those are covered by the linked child guides such as the API-and-pricing guide.
