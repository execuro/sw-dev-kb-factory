## What it is

Shopware PWA is a Single Page Application (SPA) based on JavaScript and Vue.js that can be used as the base for a decoupled storefront. It already integrates much of the Shopware functionality into a very extensible frontend application, and is built on the Store API.

## When to use

Consider Shopware PWA when a decoupled storefront for customers is needed. However, the documentation states that Shopware PWA is currently in maintenance mode, and recommends using Composable Frontends instead as the future of headless commerce with Shopware.

## Essential identifiers

- Shopware PWA (SPA, JavaScript/Vue.js based)
- Store API (the API the PWA is built on)
- Composable Frontends (recommended successor)

## Gotchas

Shopware PWA is currently in maintenance mode; the documentation directs new decoupled-storefront projects toward Composable Frontends instead.
