## What it is

This page covers client and server routing for the Sales Agent application, which is built on Nuxt and follows Nuxt's own routing conventions.

## When to use

Refer to the Nuxt documentation for details on how server and client routes work internally when working on Sales Agent routing. To get an up-to-date overview of all routes for the application, use the Nuxt dev tools, which are enabled by default during local development.

## Essential identifiers

- Nuxt server routes (`server/` directory structure)
- Nuxt client/page routes (`pages/` directory structure)
- Nuxt dev tools (route overview, enabled by default locally)

## Gotchas

Route documentation is not maintained in this page directly — the source defers to the upstream Nuxt documentation for how server and client routing work, and to the Nuxt dev tools for the current, up-to-date list of routes.
