## What it is

Sales Agent is a project designed to streamline communication and sales processes between sales representatives and customers, letting representatives handle tasks in an optimized environment without the overhead of the Shopware Administration. It is a licensed application, not open source, and is a standalone Nuxt-based frontend app hosted on its own domain separate from the default Storefront.

## When to use

Use when a merchant with a Beyond or Evolve license needs a dedicated frontend for sales representatives to interact with customers outside the Administration.

## Key steps / config

- Access requires a support ticket in the Shopware Account and validation or purchase of the Beyond or Evolve license, granting access to a private GitLab repository.
- Minimum requirements: `node` >= v18, `pnpm` >= 8, Shopware Frontends framework based on Nuxt 3, a Shopware 6 instance (version 6.5 and above) with a Beyond or Evolve license.
- API documentation is available describing the available endpoints and functionalities.
