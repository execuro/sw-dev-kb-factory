## What it is
On a high level, Shopware consists of multiple modules that separate the entire code base into logical units.

## When to use
Use this page as the entry point for understanding how Shopware's codebase is divided into modules before reading about specific components such as the Storefront or Administration.

## Key steps / config
Some modules are independent of each other, while others depend on one another.

## Essential identifiers
- Module
- Logical unit
