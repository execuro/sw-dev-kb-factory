## What it is
The Admin API provides CRUD (create, read, update, delete) operations for every entity within Shopware. It is the API used to build integrations between Shopware and external systems.

## When to use
Reach for the Admin API when you need programmatic back-end access to Shopware's data model — for example, an integration that needs to create, read, update, or delete entities such as products, customers, or orders from an external system.

## Essential identifiers
- `Admin API`
- CRUD operations (create, read, update, delete)

See [Guides – Integrations API](platform/dev/6.6/guides/integrations-api/_index.md) for more on building integrations against it.
