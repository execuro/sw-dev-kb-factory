## What it is

Guide to creating and installing an empty, running Shopware project for local development using the `ghcr.io/shopware/docker-dev` image, which runs PHP and Composer inside Docker and generates a `compose.yaml` and `Makefile`. The container shell includes the [Shopware CLI](platform/dev/6.7/products/tools/cli/_index.md).

## When to use

Starting local development without installing PHP or Composer on the host. For Docker in production see [Docker for production](platform/dev/6.7/guides/hosting/installation-updates/docker.md).

## Key steps / config

Prerequisites: Docker or OrbStack running; ports (typically `80`/`8080`) free — check with `lsof -iTCP:80 -sTCP:LISTEN` (macOS/Linux) or `netstat -aon | findstr LISTENING | findstr :80` (Windows); `make` installed (`apt install make` / `brew install make`).

1. Optional pre-pull: `docker pull ghcr.io/shopware/docker-dev:php8.3-node24-caddy`
2. `mkdir my-project && cd my-project`
3. Create the project in the current directory:
   `docker run --rm -it -v $PWD:/var/www/html ghcr.io/shopware/docker-dev:php8.3-node24-caddy new-shopware-setup`
   Append a version (e.g. `new-shopware-setup 6.6.10.0`) to pin Shopware. Answer the prompt "Do you want to use Elasticsearch? (y/N)": `y` adds an OpenSearch service to the stack, `N` uses MariaDB for search.
4. `make up` — starts web server, database, search, Mailpit etc. in the background. Check health with `docker compose ps`.
5. `make setup` — runs the Shopware installer in the web container (no browser wizard): creates the MariaDB database and admin user `admin` / `shopware`. The app connects to the database via Docker service name `database`; credentials are defined in `compose.yaml`.
6. Verify on localhost port 8000.

Lifecycle: `make up` (start), `make down` (stop), `docker compose down -v` (full reset; removes containers, networks and volumes — all data lost).

Next: [review the project structure](platform/dev/6.7/guides/installation/project-overview.md).

## Gotchas

- The setup installs `require-dev` dependencies and `shopware/dev-tools` (Symfony profiler, demo data, linting, test tooling).
- Docker images include all required PHP extensions, so the installer's system check always passes.
- `docker compose down -v` deletes all stored data.
