## What it is

Index page for the B2B Suite Administration component. B2B Suite Administration modules are built following the official Shopware Administration plugin documentation (https://developer.shopware.com/docs/guides/plugins/plugins/administration/); there is no separate B2B-specific Administration framework described here.

## When to use

When extending or building Administration modules for the B2B Suite, follow the general Shopware Administration plugin guides. For merchant-facing usage of the B2B Suite Administration, see the user documentation at https://docs.shopware.com/en/shopware-6-en/extensions/b2b-suite-administration.
