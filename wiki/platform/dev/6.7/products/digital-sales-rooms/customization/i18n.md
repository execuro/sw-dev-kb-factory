## What it is

How to customize the internationalization (i18n) setup of the Digital Sales Rooms (DSR) Nuxt 3 frontend through a customization layer, extending or overriding the default i18n configuration and translation files without modifying core files.

## When to use

You need to change or add translations, or adjust language settings, in the DSR frontend.

## Key steps / config

1. In your layer's `nuxt.config.ts`, register the `@nuxtjs/i18n` module and set the language directory, spreading the existing `i18nConfig`:

```js
modules: [
  "@nuxtjs/i18n",
],
i18n: {
  langDir: "./i18n/src/langs/",
  ...i18nConfig,
},
```

2. Create an `i18n` folder structure in your custom layer that mirrors the default layer's structure, but only add the files you want to override.
3. Use the `example` layer as the reference for the folder structure.

## Essential identifiers

- `@nuxtjs/i18n` — Nuxt i18n module
- `i18n.langDir` — `"./i18n/src/langs/"`
- `i18nConfig` — default config object spread into `i18n`
- `nuxt.config.ts`

## Gotchas

- Mirror only the files you override; the rest comes from the default layer.
