## What it is

How to customize the internationalization (i18n) setup of the Digital Sales Rooms (DSR) Nuxt 3 frontend through a customization layer, extending or overriding default translations without modifying the core files.

## When to use

You need to change or add translation strings or language configuration in the DSR frontend.

## Key steps / config

1. In your layer's `nuxt.config.ts`, register the i18n module and point it at the language directory:

```js
modules: [
  "@nuxtjs/i18n",
],
i18n: {
  langDir: "./i18n/src/langs/",
  ...i18nConfig,
},
```

2. Create the i18n folder structure in your custom layer, mirroring the default layer's structure, but only add the files you want to override.
3. Use the shipped `example` layer as reference for the structure.

## Essential identifiers

- `@nuxtjs/i18n` — Nuxt i18n module
- `i18n.langDir` — `"./i18n/src/langs/"`
- `i18nConfig` — spread default i18n configuration
- `nuxt.config.ts`

## Gotchas

- Only files present in your layer override the defaults; do not copy the whole default language set unless you want to replace it.
