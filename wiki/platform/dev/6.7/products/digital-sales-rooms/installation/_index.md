## What it is

Section overview for installing the **Digital Sales Rooms** (DSR) plugin into an already running Shopware platform. It covers installation on the admin side and of the frontend template; it does not explain installing Shopware itself.

## When to use

You are adding DSR to an existing shop and need the installation steps for plugin (admin) and frontend app.

## Key steps / config

- Example setup assumed throughout the section: Shopware platform at `https://shopware.store`, DSR frontend app at `https://dsr.shopware.io`.
- Installation is split into the admin part and the template (frontend) part, documented on the child pages.

## Gotchas

- A working Shopware installation is a prerequisite; this section does not cover it.
