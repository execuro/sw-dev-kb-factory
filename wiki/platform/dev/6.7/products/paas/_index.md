## What it is

The entry page for Shopware's two cloud-based hosting offerings, explaining how they differ in specialization and flexibility.

## When to use

Choosing between Shopware PaaS and Shopware PaaS Native for hosting and developing a Shopware project.

## Key steps / config

- **Shopware PaaS**: a generic PaaS provider supporting various applications and multiple cloud providers. Developers define infrastructure as code, which means customers manage more of the infrastructure and setup.
- **Shopware PaaS Native**: optimized solely for Shopware, a tightly integrated and controlled environment on AWS. Shopware manages all underlying configuration, so developers concentrate on application development; the docs state this gives higher stability.
