## What it is

Entry page for deploying the Sales Agent frontend app. Like all templates generated by Shopware Frontends, it can be deployed in several ways depending on the setup — most commonly to a static hosting service or to a server with a Node.js runtime.

## When to use

- Choosing a hosting approach for the Sales Agent Nuxt app.
- Finding the Sales Agent-specific deployment best practices (the section's provider guides) as an alternative to the generic approaches.

## Key steps / config

- Generic options: follow the Shopware Frontends deployment document (best practices, deployment) and the Nuxt deployment instructions (nuxt.com/deploy).
- Sales Agent-specific options: the pages in this section describe provider-specific deployment best practices.
