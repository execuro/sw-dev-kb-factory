## What it is

The entry page for the Sales Agent frontend app deployment best practices. The Sales Agent frontend is built on Shopware Frontends, so every template generated by Shopware Frontends can be deployed in several ways, depending on your setup. In most cases this means either a static hosting service or a server that provides a Node.js runtime.

## When to use

Read this page when you are about to take the Sales Agent frontend app from a local build to a hosted environment and need to pick a deployment approach. The child pages cover concrete targets: AWS Amplify, Cloudflare Pages, and an Ubuntu server running the app under PM2.

## Key steps / config

1. Decide between a static hosting service and a server with a Node.js runtime; both are supported for Shopware Frontends templates.
2. For the general deployment options, consult the Shopware Frontends deployment document (Frontends best practices, "deployment") and the Nuxt deployment instructions on nuxt.com, which list the different provider approaches.
3. For the Sales Agent specifically, follow one of the best-practice guides in this section (AWS Amplify, Cloudflare, Ubuntu Server with PM2).
