## What it is

How to customize the internationalization (i18n) setup of the Sales Agent Nuxt 3 frontend through your customization layer, extending or overriding default translations without modifying core files.

## When to use

When you need to change existing texts, or adjust language configuration, in the Sales Agent app.

## Key steps / config

1. In your layer's `nuxt.config.ts`, register the module and configure the language directory and locales:

```js
modules: ["@nuxtjs/i18n"],
i18n: {
  langDir: "./i18n/src/langs/",
  locales: [
    { code: "en-GB", iso: "en-GB", file: "en-GB.ts" },
    { code: "de-DE", iso: "de-DE", file: "de-DE.ts" },
  ],
},
```

2. Create the i18n folder structure in the custom layer, mirroring the default layer's structure but containing only the files you override.
3. Use the `example` layer in the frontend source as the structural reference.

## Essential identifiers

- `@nuxtjs/i18n`
- `i18n.langDir` = `./i18n/src/langs/`
- `i18n.locales[]`: `code`, `iso`, `file` (`en-GB.ts`, `de-DE.ts`)
