## What it is

The index page of Shopware's code guidelines: a developer handbook listing dos and don'ts and describing how functions, blocks, classes, methods, arguments, return values and files may be used. The guidelines aim to improve readability, reproducibility and usability of the code base.

## When to use

Open this section before writing or reviewing code for Shopware core or extensions when you need the project's conventions. The individual subsections (for example backward compatibility, contribution rules and the core PHP language-feature guidelines) hold the concrete rules; this page only routes to them.
