## What it is

A core coding guideline (dated 2023-05-16, mirrored from the Shopware repository's coding guidelines) written when Shopware 6.5 raised the minimum to PHP 8.1 and Symfony 6.1. It promotes the newer language and framework features to reduce boilerplate and prevent common mistakes, and gives a BC/migration note per feature.

## When to use

When writing or refactoring core or extension PHP code and deciding which syntax to prefer, or whether converting existing code is a BC break.

## Key steps / config

**PHP 8.0/8.1 features to use**

- **Promoted properties** — declare properties in the constructor: `public function __construct(private int $x, private int $y) {}`. Existing code was refactored with Rector; migrating is not a BC break.
- **New in initializers** — object defaults: `private Hasher $hasher = new Bcrypt()`. Not a BC break.
- **`match` instead of `switch`** — strict comparison, no fall-through, returns a value, throws `UnhandledMatchError` when no arm matches and there is no `default`. Rector-refactored.
- **String functions** — `str_contains`, `str_starts_with`, `str_ends_with` instead of `strpos` checks.
- **Named arguments** — e.g. `htmlspecialchars($string, double_encode: false);`; useful for skipping defaults and labelling `true`/`false`/`null`-style values. Allowed for Shopware and PHP APIs.
- **Native types** — union (`int|string`), `mixed`, intersection (`MyService&MockObject`); keep `@var`/`@param` only for array shapes, generics and types like `class-string`, `positive-int`.
- **Enums** — replace constant lists; work with `match`, can be type-hinted, backed enums offer `MyEnum::from()` / `MyEnum::tryFrom()`, can implement interfaces.
- **Readonly properties** — DTOs as `public function __construct(public readonly int $productId, public readonly bool $includeStock) {}`.
- **First-class callables** — `strlen(...)`, `$object->doCoolStuff(...)`, `\My\Object::doCoolStuff(...)`.
- **Attributes** instead of docblock annotations (Rector-refactored), e.g. on a controller action:

```php
use Symfony\Component\Routing\Attribute\Route;

#[Route('/blog', name: 'blog_list')]
public function list(): Response
```

- **Nullsafe operator** — `$user?->address?->addressLine2`; short-circuits the rest of the chain.
- Also: `never` return type, `array_is_list`, `final const`, `$object::class`, array unpacking with string keys.

**Symfony 6.1 features**

- Enum route requirements: `requirements: ['bar' => new EnumRequirement(SomeEnum::class)]` (`Symfony\Component\Routing\Requirement\EnumRequirement`).
- Service autowiring attributes from `Symfony\Component\DependencyInjection\Attribute\Autowire`, e.g. `#[Autowire(service: 'email_adapter')]` or `#[Autowire('%kernel.debug_mode%')]` on constructor arguments; decoration via attributes is also possible.
- Console autocompletion: pass a closure as the 5th argument of `addArgument()`/`addOption()`, e.g. `fn () => self::availableFeatures()`.

## Essential identifiers

- `UnhandledMatchError`, `str_contains`, `str_starts_with`, `str_ends_with`
- `Symfony\Component\Routing\Attribute\Route`
- `Symfony\Component\Routing\Requirement\EnumRequirement`
- `Symfony\Component\DependencyInjection\Attribute\Autowire`

## Gotchas

- `switch` to `match` can be a BC break: `switch` compares loosely and silently ignores unhandled values, `match` is strict and throws. Check value types and that all cases are handled.
- Private properties not written after instantiation can become `readonly` without a BC break; adding `readonly` to existing public/protected properties is a BC break (new code may use it).
- Named arguments couple call sites to parameter names; Shopware announces parameter renames ahead of a major so tooling can update named call sites, positional calls are unaffected.
- The guideline imports `Symfony\Component\Routing\Annotation\Route`; core 6.7 code imports the `Attribute` namespace variant instead.
- Enum migration and Symfony dependency management have their own ADRs (Use PHP 8.1 Enums; Symfony Dependency Management, superseded).

## Version notes

- Minimum PHP 8.1 / Symfony 6.1 applies from Shopware 6.5 per this guideline.
