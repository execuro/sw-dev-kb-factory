## What it is

The landing page of the "Documentation Guidelines" section (navigation title "Document"). It tells contributors that this section covers how to write articles for the Shopware developer documentation, which language usage, fonts and formats to follow, and the step-by-step documentation process.

## When to use

When you contribute to the Shopware developer documentation and need the house rules for writing an article, its language and formatting, or the workflow a documentation change goes through. The detailed rules live on the sub-pages of this section; this page only introduces them.
