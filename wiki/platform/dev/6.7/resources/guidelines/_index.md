## What it is

The landing page of the Guidelines section for Shopware 6.7. It is addressed to all readers and contributors and groups three kinds of rules: coding guidelines, documentation guidelines and testing guidelines. Its purpose is to keep code and docs consistent, promote best practices and make collaboration between contributors work.

## When to use

Start here when you contribute to Shopware (code or documentation) and need to find which standard applies to your change.

## Key steps / config

- **Code** section: lays out the coding standards so that anyone can understand and modify the code at any point while it stays consistent. Subpages cover topics such as backward compatibility and contribution rules.
- **Documentation** section (`documentation-guidelines`): describes language style, grammar, markdown syntax and the documentation process for writing Shopware docs.
- Testing guidelines are named as part of the set, alongside coding and documentation rules.
