## What it is

The entry page of Shopware's guidelines for readers and contributors. Shopware defines coding, documentation, and testing guidelines to keep contributions consistent, promote best practices, and support collaboration. The page points to two child sections:

- **Code** (`code/`) — the coding standards. They exist so that anyone can understand and modify the code at any point while the codebase stays consistent.
- **Documentation guidelines** (`documentation-guidelines/`) — the language style, grammar, markdown syntax, and the documentation process.

## When to use

- Before contributing code to Shopware: open the Code section to follow its coding standards.
- Before writing or changing Shopware documentation: open the documentation guidelines for style, grammar, markdown and the review process.
- When reviewing a contribution and you need the agreed reference for consistency.
