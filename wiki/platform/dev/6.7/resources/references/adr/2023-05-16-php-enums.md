## What it is

Architecture decision record (area: core, 2023-05-16): all new code that represents a fixed collection of constant values uses PHP Enums instead of class constants plus validation arrays. Existing constant lists should be migrated where possible, in a backwards compatible way.

## When to use

- Designing an API parameter that accepts one of a predefined set of values (examples from the ADR: product types Parent/Variant, product status Enabled/Disabled, backup type Full/Incremental).
- Migrating an existing `public const` list plus `in_array` validation to an enum without breaking callers.

## Key steps / config

Expand & Contract migration for a method that takes a "type" string (`IndexMethod` / `Indexer` are the ADR's illustrative names, not Shopware classes):

1. Create the enum and widen the parameter to accept both, keeping the constants:

```php
enum IndexMethod
{
    case PARTIAL;
    case FULL;
}
public function product(int $id, IndexMethod|string $method): void
```

2. Convert strings to the enum at the start of the method, e.g. `match ($method) { 'partial' => IndexMethod::PARTIAL, 'full' => IndexMethod::FULL, default => throw new \InvalidArgumentException() }`, then `match` on enum cases. For backed enums, `BackedEnum::from` does casting and validation; pure enums need a manual mapping.
3. Deprecate the constants and primitive input:
   `// @deprecated tag:v6.6.0 - Constant will be removed, use enum IndexMethod::PARTIAL` and on the method `@deprecated tag:v6.6.0 - Parameter $method will not accept a primitive in v6.6.0`.
4. In the next major, remove constants and the string branch: `public function product(int $id, IndexMethod $method): void`, called as `(new Indexer())->product(1, IndexMethod::PARTIAL);`.

## Essential identifiers

- `enum` / `case` — PHP enum declaration
- `BackedEnum::from` — casting for backed enums
- `@deprecated tag:v6.6.0` — deprecation annotation format used in step 3

## Gotchas

- In PHP 8.1 an enum cannot be assigned directly to a constant; PHP 8.2 allows `public const PARTIAL = IndexMethod::PARTIAL->value;` with backed enums.
- During the transition, allowed values must be maintained in both the constants and the enum.

## Version notes

The ADR is based on PHP 8.1 being the minimum from Shopware 6.5. The installed 6.7.13 core requires PHP `~8.2.0 || ~8.3.0 || ~8.4.0 || ~8.5.0`, so the PHP 8.2 constant-from-enum form is available.
