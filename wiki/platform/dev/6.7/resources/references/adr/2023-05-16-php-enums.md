## What it is

Architecture decision record (2023): since Shopware 6.5 requires PHP 8.1, all new code that represents a collection of constant values uses native PHP enums instead of class constants plus validity arrays. Existing constant lists should be migrated where possible, using the Expand & Contract pattern to stay backwards compatible.

## When to use

- Adding a new "type"/"status"-like parameter with a predefined value list (examples from the ADR: product types Parent/Variant, product status Enabled/Disabled, backup type Full/Incremental).
- Migrating an existing API that accepts a string validated against class constants.

## Key steps / config

Starting point: a class with `public const PARTIAL = 'partial'; public const FULL = 'full';` and a method `product(int $id, string $method)` that validates with `in_array(...)` and dispatches with `match`.

1. **Expand** — create the enum and widen the parameter to accept both, keeping the constants in parallel:

```php
enum IndexMethod
{
    case PARTIAL;
    case FULL;
}

public function product(int $id, IndexMethod|string $method): void
```

2. **Convert** — if a string is passed, map it to the enum case (`match ($method) { 'partial' => IndexMethod::PARTIAL, 'full' => IndexMethod::FULL, default => throw new \InvalidArgumentException() }`), then `match` on the enum only. For a backed enum, `BackedEnum::from` performs casting and validation automatically; a pure enum needs manual mapping.
3. **Deprecate** — mark the constants and primitive parameter values, e.g. `// @deprecated tag:v6.6.0 - Constant will be removed, use enum IndexMethod::PARTIAL` and `@deprecated tag:v6.6.0 - Parameter $method will not accept a primitive in v6.6.0`.
4. **Contract** — in the next major, remove the constants and the string branch: `product(int $id, IndexMethod $method)`, called as `(new Indexer())->product(1, IndexMethod::PARTIAL);`.

## Essential identifiers

- `enum IndexMethod` (example), `IndexMethod|string` union parameter
- `BackedEnum::from`
- `@deprecated tag:v6.6.0` annotation format

## Gotchas

- In PHP 8.1 a constant cannot be assigned an enum; PHP 8.2+ allows it with backed enums: `public const PARTIAL = IndexMethod::PARTIAL->value;`. The installed 6.7 core requires PHP 8.2 or newer, so this form is available.
- Keep the allowed values maintained in both constants and enum until the deprecation is removed.
