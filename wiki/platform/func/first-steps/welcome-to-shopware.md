## What it is
This page introduces the Shopware web properties available to a new Shopware user, beyond their own shop.

## When to use
Use it as a starting-point map after choosing Shopware, to find the right Shopware resource for a given need.

## Key steps / config
- Shopware website (`https://www.shopware.com/en/`) — product info, version comparisons, partner listing, further-education offer, blog.
- Community Store (`https://store.shopware.com/en`) — third-party extensions and payment provider interfaces; also where you can offer your own extension.
- Shopware Account (`https://account.shopware.com/`) — view bookings and invoices, change stored data, ask support, see a plan overview.
- Shopware Docs — how-to content for building articles and configuring the shop.
- Developer documentation (`https://developer.shopware.com/docs/`) — technology behind Shopware, plugin development, design customization, plus a blog.
- Community Hub (`https://hub.shopware.com/`) — interactive learning paths to explore Shopware step by step.
- Product Feedback Portal (`https://feedback.shopware.com/`) — submit problems, ideas, solutions and use cases that can influence future features.
- Shopware forum (`https://forum.shopware.com/`) — exchange ideas and experiences with other shop owners.
- GitHub Issues (`https://github.com/shopware/shopware/issues`) — report reproducible bugs for developer triage and prioritization.

## Essential identifiers
