## What it is

Shopware Commercial is the extension that unlocks the features included in a shop's booked plan (Rise, Evolve or Beyond). Future features and innovations are delivered exclusively through this extension.

## When to use

Use it whenever a shop needs to activate paid-plan features (AI Copilot, Rule Builder preview, Flow Builder sharing/webhooks/delayed actions, Returns management, Multi-inventory, Subscriptions, B2B components, Sales Agent, Advanced Search 2.0, etc.) matching its booked plan.

## Key steps / config

- Cloud shops: the extension is pre-installed (not listed under My Extensions, but active).
- Self-hosted shops: install manually under **Extensions > My Extensions > Shopware Commercial**, then activate it, or add it via **Extensions > Store** by searching for "Shopware Commercial".
- Once activated, the booked plan is matched and its features are unlocked automatically.
- Installing/activating the plugin adds additional CLI commands to the shop.

## Essential identifiers

- Admin path: **Extensions > My Extensions**
- Plans gating features: Shopware Rise, Shopware Evolve, Shopware Beyond

## Gotchas

In the self-hosted variant, the extension must be installed manually; in the cloud variant it is already present and does not need separate installation.
