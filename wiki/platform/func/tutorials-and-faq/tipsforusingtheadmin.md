## What it is

Tips for working efficiently in the Shopware administration: using multiple browser tabs
at once, and a reference of keyboard shortcuts for common admin actions.

## When to use

When a user wants to work in several admin areas simultaneously, or speed up navigation
and common actions (save, cancel, cache clear, add item) via the keyboard.

## Key steps / config

- **Multi-browsertab usage**: open several admin functions at once via right-click +
  "Open in new tab" — all tabs share the same login session; logging out once logs out
  all open tabs automatically.
- Open the full shortcut overview in the admin with **Shift + ?**.
- **Simultaneous-press shortcuts**: `f` focuses search; `Shift + ?` opens the shortcut
  listing; `alt + s` (Windows/Linux) or `control + s` (Mac) saves the detail view;
  `Esc` cancels the detail view; `alt + c` (Windows/Linux) or `control + c` (Mac) clears
  the cache.
- **Sequential add-item shortcuts** (press keys quickly one after another):
  `A + P` add product, `A + C` add category, `A + E` add Shopping Experience layout,
  `A + U` add customer, `A + P + R` add properties, `A + M` add manufacturer,
  `A + R` add rule, `A + S` add sales channel.
- **Sequential navigation shortcuts**: `G + H` dashboard, `G + P` products,
  `G + C` categories, `G + D` dynamic product groups, `G + P + R` properties,
  `G + M` manufacturers, `G + O` orders, `G + U` customers,
  `G + E` Shopping Experiences, `G + M + E` Media, `G + P + O` promotions,
  `G + N` newsletter recipients, `G + S` settings listing, `G + S + N` snippets,
  `G + S + P` payment, `G + S + S` shipping, `G + S + R` rule builder, `G + A` plugins.

## Essential identifiers

- `Shift + ?` (shortcut listing), `f` (focus search)
- `alt + s` / `control + s` (save detail view), `Esc` (cancel detail view)
- `alt + c` / `control + c` (cache clear)
