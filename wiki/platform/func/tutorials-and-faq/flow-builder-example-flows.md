## What it is
A set of example Flow Builder configurations for common storefront/order automation tasks: customer tagging, document delivery, warehouse notification, and external webhook notification.

## When to use
When building flows for tagging customers by origin, limiting a product to one purchase per customer, auto-attaching documents to confirmation emails, notifying a warehouse on payment, or sending order data to an external service like Slack.

## Key steps / config
- **Tag new customers by country**: trigger **Checkout / Customer / Register**; add conditions checking the customer's country (USA/Austria/Switzerland) and the action **Assign tag** per matching branch; no tag if none match.
- **Item orderable only once per customer**: first create a Rule Builder rule such as **Item in cart > is one of > <item>**; in the "Order placed" flow add a condition using that rule, then the action **Assign tag** on the customer. The Dynamic Access extension can then hide the item for tagged customers, or a shipping method can be disabled for them.
- **Send documents automatically**: trigger **Checkout / Order / Placed**; action **generate document** selecting the document type (e.g. **invoice**); then action **send email** with recipient **default** and the desired email template (e.g. **order confirmation**), attaching the generated document.
- **Notify the warehouse of a paid order**: trigger **State enter / Order transaction / State / Paid**; action **create document** (e.g. **invoice**); action **Send email** with recipient **custom** set to a specific email address; select an appropriate template (e.g. the default template for "Enter payment state: Paid") and the document(s) to attach — the documents must have been generated by the earlier action in the same flow.
- **Notification to an external platform (Slack)**: requires the **Flow Builder Professional for Shopware 6** extension for the **Webhook** action. In Slack's Workflow Builder, create a workflow with a **webhook** trigger and a **send message** step, saving the webhook URL and the HTTP example JSON shape. In Shopware Flow Builder, use trigger **Checkout / Order / Placed** (or **State Enter / Order Transaction / State / Paid**), then action **Call URL (Webhook)** with method **POST**, the Slack webhook URL, and body type **Raw** containing the JSON payload with Shopware template variables such as `{{ order.id }}`, `{{ order.orderNumber }}`, and iterating `order.LineItems` for line items, e.g.:
```json
{
  "orderURL": "...",
  "orderPositions": "...",
  "orderNumber": "{{ order.orderNumber }}",
  "orderCustomerAdress": "..."
}
```

## Essential identifiers
Triggers: `Checkout / Customer / Register`, `Checkout / Order / Placed`, `State enter / Order transaction / State / Paid`. Actions: `Assign tag`, `generate document` / `create document`, `send email`, `Call URL (Webhook)`. Extension: **Flow Builder Professional for Shopware 6**.

## Gotchas
For the warehouse-notification flow, the documents selected for attachment must already have been generated by an earlier action in the same flow — otherwise there is nothing to send.
