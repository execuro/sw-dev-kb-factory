## What it is

A short pointer page: use a copy of your shop to test changes, updates and new features without affecting the live shop. Starting with Shopware 6.6.1.0, staging mode can be enabled on that copy.

## When to use

Use it before applying updates or new features to a live shop.

## Version notes

Staging mode is available from Shopware 6.6.1.0. The activation steps are in the developer documentation: https://developer.shopware.com/docs/guides/hosting/installation-updates/creating-a-staging-instance.html#activate-the-staging-mode
