## What it is
Describes the Insider Previews feature for testing upcoming Shopware functions early via the Admin Help menu. This article applies only to Shopware versions 6.6.8.1 to 6.6.10.5; newer versions have a separate current Insider Previews page.

## When to use
When you want to try new Shopware functions before general release and give feedback during the beta phase — recommended first in a staging environment before production use.

## Key steps / config
1. Open the info area for Insider Previews via the **Help menu** at the top right of the Admin; it also notifies you when a new feature is available.
2. Click **View features** to see the overview of available features.
3. Before use, agree that Shopware may address or read certain API endpoints.
4. Two feature types are offered: **Blueprint** (early, experimental, may not be pursued depending on feedback) and **Beta** (closer to release-candidate quality).
5. Click **Enable** on a feature to activate it; most features link to the Shopware feedback portal for direct input.
6. Before using Insider Previews, activate anonymized data transmission under **Settings > System > Share data** — if not already enabled, a message appears during activation.

## Essential identifiers
Admin path: **Help menu > View features**; setting **Settings > System > Share data**; feature types **Blueprint**, **Beta**.

## Gotchas
This article covers only Shopware versions 6.6.8.1 through 6.6.10.5 — for newer versions, the Insider Previews documentation has moved to a different page.
