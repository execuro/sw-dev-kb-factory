## What it is

Dynamic Access lets a merchant define who can access shop content, showing content only to certain customer groups via the Rule Builder.

## Key steps / config

- Combine Dynamic Access with the Rule Builder to control access.
- Control who sees categories, products, specific variants, or landing pages.

## Essential identifiers

- `Dynamic Access`
- `Rule Builder`
