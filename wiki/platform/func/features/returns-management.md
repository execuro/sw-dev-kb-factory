## What it is

Returns Management is a Shopware feature for handling customer returns. Without it, only a whole order can be returned and partial returns are not possible. The feature introduces a basis for creating a return and keeping a status per item in Shopware, so returns can be handled manually in the Administration. Detailed usage is documented on the returns management page in the orders section of the merchant documentation.

## When to use

- A customer has sent back goods from an order and you need to record the return in the Administration.
- Only some items of an order are returned and you need a per-item status instead of returning the whole order.
