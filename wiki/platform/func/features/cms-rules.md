## What it is

CMS rules enable rule-based display of content: individual blocks of shop content can be shown only to certain target groups, using the Rule Builder for precision targeting, discounts and offers.

## Key steps / config

- Use the Rule Builder to determine which target groups view certain pieces of shop content.
- Conditions can be based on the day, time, cart contents or customer status.

## Essential identifiers

- `CMS rules`
- `Rule Builder`
