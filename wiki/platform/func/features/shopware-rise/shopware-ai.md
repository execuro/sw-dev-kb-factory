## What it is
Shopware AI is a set of AI Copilot features built into the Shopware Administration and storefront search that assist merchants with various e-commerce tasks. It is part of the AI Copilot and requires the "Commercial Extension".

## When to use
Use it when you want AI-assisted content generation, classification, search, or translation across the Administration and storefront.

## Key steps / config
Available AI Copilot features:
- AI-generated content for Shopping Experiences — creates and translates text content, checks spelling.
- Image keyword assistant — analyzes uploaded images and assigns relevant keywords.
- AI-generated product properties — suggests product properties from a product description.
- Custom checkout message — sends a customized AI-generated post-purchase message based on the customer's cart.
- AI-generated summary of ratings — summarizes all reviews for a product on the product detail page.
- AI-based customer classification — generates labels from customer order history, usable as tags for marketing mailings.
- AI export assistant — exports specific Shopware data as a CSV file.
- AI-based translation for reviews — translates product reviews.
- AI description assistant — generates a product description from a few keywords.
- Search by context — lets buyers search for products using keywords or sentences.
- Search by image — buyers upload an image and receive suggestions of similar items.
- Text to image — generates images from natural-language prompts.
