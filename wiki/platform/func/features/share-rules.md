## What it is
Share Rules is a Rule Builder capability that lets merchants export rules from one Shopware system and import them into another.

## When to use
Use it to transfer a rule between systems — for example, sending a rule to an app, or moving a rule from a test system to a live system.

## Key steps / config
- Export a rule from the Rule Builder.
- Transfer the exported rule to the target system.
- Import the rule into the Rule Builder of the target system.

The Rule Builder itself lets merchants define and manage business rules without writing code, driving behaviours based on conditions — for example, dynamically adjusting pricing, controlling access to functions, or applying discounts for specific customer groups.
