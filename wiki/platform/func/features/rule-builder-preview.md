## What it is

Rule Builder preview mode lets admins check the rules they have created in the Rule Builder — e.g. for calculating shipping costs or customer-specific product prices — directly after creation in the admin.

## When to use

When creating or editing a rule and needing to verify it works as intended before relying on it in production, e.g. finding errors in a rule's structure.

## Key steps / config

- Create new rules in the Rule Builder.
- Test rules directly in the admin with concrete orders to check whether they work as planned.

## Essential identifiers

- `Rule Builder`
- preview mode
